# Security

Computah can read and operate other apps through macOS Accessibility permission.
It sends selected app content to TypeSafe and microphone audio to Deepgram.
Read [privacy](docs/PRIVACY.md) before you use Computah with private content.

Do not put secrets or raw app captures in a public issue.
Report a security problem privately to the repository maintainers.
If no private contact is listed, open an issue to ask for one.
Do not include vulnerability details or private data in that issue.

Replace any API key that was exposed.
Removing a key from a file does not make the old key safe to use again.

This project is experimental. It has no guarantee of security support.
